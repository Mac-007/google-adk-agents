# Google ADK Based Agent Exploration

A collection of experiments and implementations exploring **Google Agent Development Kit (ADK)** and agent-based application development.

This repository focuses on working with ADK agents, model integrations, runners, environment configuration, and related agent capabilities.

## Current Setup

* Python
* Google ADK
* LiteLLM
* `uv` for dependency and environment management
* Environment-based API configuration


## Configuration

Create a `.env` file in the project root:

```env
OPENROUTER_API_KEY=your_api_key_here
```

## Setup

Install the project dependencies:

```bash
uv sync
```

Or add the required packages:

```bash
uv add google-adk litellm python-dotenv
```
